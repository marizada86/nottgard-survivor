# Runtime Godot para Testes

Este projeto de teste usa o runtime portatil abaixo.

| Campo | Valor |
| --- | --- |
| Godot | 4.7.2 stable |
| Plataforma | Windows 64-bit |
| Pacote | `godot-v4.7.2-stable-win64.zip` |
| SHA-256 do pacote | `ac1eddfaa82b4375e31fe383cbc114159aca503ec71bd874831effc7a29a6829` |

Baixe o pacote na Release `godot-v4.7.2-win64`, extraia os dois executaveis em
uma pasta e abra este projeto pelo `Godot_v4.7.2-stable_win64.exe`.

O arquivo `SHA256SUMS.txt` da Release tambem lista os hashes de cada executavel.
